Exemplos de herança em Java
Compreenda neste vídeo como a herança em Java ajuda a criar sistemas organizados e reutilizáveis. A partir de cenários reais, como locadoras de veículos e lojas virtuais, aprenda a estruturar superclasses e especializar comportamentos, promovendo clareza, escalabilidade e manutenção eficiente no desenvolvimento orientado a objetos.



Vamos agora exercitar os conceitos de herança! Cada cenário foi escolhido para refletir problemas comuns no desenvolvimento de sistemas, em que a herança pode trazer clareza, reutilização de código e estrutura mais coesa. 


Veículos em uma locadora



Imagine que você está desenvolvendo um sistema para uma locadora de veículos. Eles possuem dados em comum (como marca, modelo e placa), mas também características específicas conforme o tipo (carro, moto ou caminhão).

 

A classe base Veiculo armazena os dados que todos os veículos compartilham. Note que o atributo placa é privado, e os demais são protegidos para permitir acesso controlado pelas subclasses. Além disso, o método getDescricao() pode ser reaproveitado por todas as subclasses. Confira!

 

Classe Base:


Java (OpenJDK 13.0.1)

public class Carro extends Veiculo {
    private int numeroPortas;

    public Carro(String marca, String modelo, String placa, int numeroPortas) {
        super(marca, modelo, placa);
        this.numeroPortas = numeroPortas;
    }

    public int getNumeroPortas() {
        return numeroPortas;
    }
}

Produtos em um e-commerce


Vamos modelar um sistema para um e-commerce com produtos variados. A classe base Produto contém os atributos nome e preço, que são comuns a todos os produtos.

 

Classe Produto:


Java (OpenJDK 13.0.1)

public class Livro extends Produto {
    private String autor;
    private String isbn;

    public Livro(String nome, double preco, String autor, String isbn) {
        super(nome, preco);
        this.autor = autor;
        this.isbn = isbn;
    }

    public String getDetalhes() {
        return getInfo() + " | Autor: " + autor + " | ISBN: " + isbn;
    }
}

Heróis de Eldoria: estruturando os tipos de personagens


Vamos modelar a estrutura básica dos heróis do nosso jogo. Todos os personagens possuem características em comum, como nome e nível. A partir dessa base, criaremos classes mais específicas, como Guerreiros e Magos, que adicionam seus próprios atributos.


Classe Personagem


A classe base Personagem armazena os dados que todos os heróis compartilham. Ela também possui um método para retornar uma descrição básica, que será reutilizado pelas subclasses.


Java (OpenJDK 13.0.1)

public class Personagem {
    protected String nome;
    protected int nivel;

    public Personagem(String nome, int nivel) {
        this.nome = nome;
        this.nivel = nivel;
    }
    //Método base que retorna a informação comum a todos os personagens
    public String getDescricaoBase() {
        return "Nome: " + nome + " | Nível: " + nivel;
    }
}

Subclasse Guerreiro


Herda as características da classe Personagem e adiciona um novo atributo específico: forca. Ela também possui um método que reutiliza a descrição da classe pai e adiciona sua própria informação.


Java (OpenJDK 13.0.1)
public class Guerreiro extends Personagem {

    private int forca;

    public Guerreiro(String nome, int nivel, int forca) {
        super(nome, nivel);    // Chama o construtor da classe Personagem
        this.forca = forca;

    }
    // Este método utiliza o método da classe pai para construir sua descrição
    public String exibirDescricaoCompleta() {
        // Reutiliza getDescricaoBase() e adiciona a informação específica
        return getDescricaoBase() + " | Força: " + forca;
    }
}

Subclasse Mago


Herda de Personagem e adiciona o atributo inteligencia, criando um método de descrição que também aproveita a estrutura da classe pai. Veja!


Java (OpenJDK 13.0.1)
public class Mago extends Personagem {
    private int inteligencia;
    public Mago(String nome, int nivel, int inteligencia) {
        super(nome, nivel); // Chama o construtor da classe Personagem
        this.inteligencia = inteligencia;

    // Este método também reutiliza o método da classe pai
    public String exibirDescricaoCompleta() {
        return getDescricaoBase() + " | Inteligência: " + inteligencia;
    }
}

Passos para execução e teste dos exemplos


Para organizar projetos em Java em ambientes de desenvolvimento (IDEs), como Eclipse, IntelliJ ou VS Code, confira o passo a passo:

 

1. Crie um arquivo para cada classe de modelo:

 

[NomeDaClasseBase].java

[NomeDaSubclasse1].java

[NomeDaSubclasse2].java

 

2. Crie um arquivo final para a execução, por exemplo, Teste.java.
 

3. Crie o método main e cole o código do bloco "Uso:" dentro de Teste.java.

 

4. Compile e execute o arquivo Teste.java.

 

A aplicação prática da herança permite que sistemas sejam construídos com maior organização e reaproveitamento de código. A definição clara de superclasses e subclasses evita redundância e facilita futuras manutenções. Assim, ao estruturar seu código com hierarquias bem definidas, você se aproxima das boas práticas da orientação a objetos, um diferencial importante para atuação em projetos reais de software. Ao compreender e exercitar esses exemplos, você está mais preparado para modelar soluções robustas e alinhadas às necessidades do mercado.
